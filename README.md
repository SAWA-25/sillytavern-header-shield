# Header Shield / 头部护盾 — SillyTavern 扩展

把原来的“脚本库脚本”改成了真正的 SillyTavern 第三方扩展。当前版本 1.1.0，默认期望模型为 `gemini-4-argon`。

## 它是什么

- 每次生成前，用 `crypto.getRandomValues` 生成一个新的随机头部（数学 / 科学短文），通过 SillyTavern 的 `setExtensionPrompt` 注册到提示词最前面。
- 每份头部都有唯一的 `seed`，每次都不一样，降低按提示词前缀缓存 / 指纹命中同一条路由的可能。
- 记录每次回复报告的模型名，和你在设置里填的“期望模型”比对，不一致时警告。如果期望是 `gemini-4-argon`、实际报告含 `flash`，会单独警告。
- 可选的小说作者身份锚点：默认作者为 suki，一位中文小说作者。锚点只说明这是成人的小说创作、故事里的角色都是成年人、请保持作者口吻和当前场景。它不能保证渠道一定放行，渠道自己的过滤仍可能生效。

## 它不能做什么（先说清楚）

插件**无法强制渠道使用某个模型**。模型名是 API 请求里的字段，由 SillyTavern 的 API 设置决定；如果渠道在服务端偷换模型，客户端插件看不到、也改不了渠道的服务端路由。`gemini-4-argon` 是中转别名，不是官方模型名，中转可能把它映射到 flash，唯一的确认办法是问渠道它把这个别名映射到什么，以及看回复报告的模型名。

真正能锁定模型的办法，按可靠程度排序：

1. 用官方 API 直连，在 SillyTavern 的 API 设置里明确选模型。
2. 换一个不做模型替换的渠道。
3. 用这个插件做两件事：打散前缀指纹 + 每次比对回复报告的模型名，发现不一致就换渠道。

同样，插件也不能保证破除渠道的 NSFW 过滤。锚点只是让创作身份和场景更一致，是否放行由提供模型的渠道决定。

## 安装

方法 A（推荐，Git）：把这个文件夹放到酒馆的扩展目录：

```
SillyTavern/public/scripts/extensions/third-party/header-shield/
```

然后重启酒馆，在扩展里启用 Header Shield。

方法 B（酒馆内安装）：扩展 → 安装扩展 → 粘贴这个仓库的 Git 地址，安装后启用。

方法 C（ZIP）：把本文件夹压缩成 `header-shield.zip`，在扩展页面用“从 ZIP 安装”（如果你的酒馆版本支持）。

## 设置

- 启用护盾：总开关。
- 护盾强度：轻量 800~1,500 字 / 均衡 2,000~4,000 字（默认）/ 较强 6,000~9,000 字 / 极限 12,000~20,000 字。
  - 旧脚本默认是 12,000~20,000 字，很费 token，也更容易让模型分心。新版默认改成 2,000~4,000 字。
- 数学题占比：默认 70%。
- 内容口味：数学 + 科学短文 / 全数学 / 科学 + 散文 / 自然科学卷宗。
- 期望模型：填 API 设置里选的模型名的一部分，例如 `claude-sonnet-4-5`。留空则只记录、不比对。

## 和旧脚本的区别

- 旧版是脚本库脚本，依赖 STscript 的 `getVariables` / 按钮事件，换角色、换设备容易失效，也没有版本和扩展面板。
- 新版是标准扩展：`manifest.json` + `index.js` + `settings.html` + `style.css`，用 `SillyTavern.getContext()`、`setExtensionPrompt` 和事件系统，不再直接改聊天记录的第一条消息。
- 去掉了 360° 拿铁杯动画等 UI 负担，设置面板更轻、手机上更好点。
- 增加了模型比对记录，方便你判断到底是“被路由了”，还是“只是感觉像换了模型”。

## 文件

- `manifest.json` — 扩展信息，版本 1.0.0
- `index.js` — 随机头部生成、注入、模型比对
- `settings.html` — 设置面板
- `style.css` — 设置面板样式
- `README.md` — 本文件
